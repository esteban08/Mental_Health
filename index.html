Metodología CRISP-ML(Q)

Cross-Industry Standard Process for Machine Learning with Quality Assurance

🎯

1. Business & Data Understanding

Definición del objetivo de negocio, métricas de éxito (Bajo/Medio/Alto) y análisis del CSV original.

🧹

2. Data Preparation (ETL)

Tratamiento de nulos, duplicados, outliers mediante IQR y estandarización de features.

🏗️

3. Modeling

Entrenamiento de algoritmos (LightGBM, Random Forest, Regresión Logística) aplicando SMOTE.

✅

4. Evaluation

Validación de métricas (Accuracy, AUC-ROC, F1-Score) y visualización de Curva ROC.

🚀

5. Deployment

Creación de dashboard interactivo en Streamlit consumiendo el modelo exportado en Joblib.

👁️

6. Monitoring & Maintenance

Documentación técnica para asegurar el seguimiento del data drift en el tiempo.

Cómo Ejecutar el Proyecto

  1. 1 Instalar dependencias: pip install -r requirements.txt
  2. 2 Ejecutar ETL: Abre y ejecuta 01_ETL.ipynb para generar cleaned_data.csv.
  3. 3 Explorar Datos: Revisa 02_EDA.ipynb.
  4. 4 Entrenar Modelo: Ejecuta 03_Modeling.ipynb para generar modelo_salud_mental.pkl.
  5. 5 Iniciar App: Ejecuta en la terminal streamlit run app.py
